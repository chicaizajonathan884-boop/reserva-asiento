# Reserva de un asiento en sala de cine

**Nombre:** Jonathan Oswaldo Chicaiza Andrango

## Objetivo
Crear un programa en Python que permita reservar un asiento de una sala de cine de 3 filas por 4 columnas, utilizando una matriz y bucles anidados.

## Funcionamiento
El programa solicita la fila y columna del asiento. Después cambia su valor de 0 a 1 y muestra la matriz completa en pantalla.

## Cómo ejecutar
Abrir el archivo `reserva_asientos.py` en Visual Studio Code y ejecutarlo con Python.
